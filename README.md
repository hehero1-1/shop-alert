# 새 상품·새 글 텔레그램 알림

정해 둔 페이지에 새 상품이나 새 글이 올라오면 텔레그램으로 알려주는 봇이에요.
GitHub 서버에서 10분마다 저절로 실행되기 때문에 내 PC는 꺼 둬도 됩니다.

## 어떻게 동작하나요

10분마다 GitHub가 `watcher.py`를 실행하면 다음 순서로 확인해요.

1. 텔레그램에서 봇에게 보낸 명령어(`/add` 등)가 있으면 먼저 처리해요.
2. `watchlist.toml`에 적힌 페이지를 하나씩 열어서 상품 번호나 글 번호를 읽어요.
3. `seen.json`(지금까지 본 번호 기록)과 비교해서 **처음 보는 번호만** 텔레그램으로 보내요.
4. 새로 본 번호를 `seen.json`에 저장해요.

가격이 바뀌거나 배너가 바뀌는 건 알림이 가지 않아요. 앞의 글이 지워지면서 아래에서 밀려 올라온
예전 글도 새 글로 치지 않아요.

| 파일 | 하는 일 |
|---|---|
| `watcher.py` | 확인하고 알림을 보내는 프로그램 |
| `watchlist.toml` | 감시할 페이지 목록 |
| `.github/workflows/watch.yml` | GitHub에 10분마다 실행하도록 예약 |
| `seen.json` | 이미 본 상품·글 기록 (처음 실행할 때 자동으로 생겨요) |

## 처음 설정하기 (한 번만, 15분 정도)

> **`알림봇-설정.html`로 설치했다면 이 부분은 건너뛰세요.** 설정 페이지가 아래 과정을 대신해 줘요.
> 아래는 설정 페이지 없이 직접 설치하는 방법이에요.

### 1. 텔레그램 봇 만들기

1. 텔레그램에서 `@BotFather`를 검색해서 대화를 시작해요.
2. `/newbot`을 보내요.
3. 봇 이름을 보내요. 아무거나 괜찮아요. (예: `내 쇼핑 알림`)
4. 봇 아이디를 보내요. 영문으로, `bot`으로 끝나야 해요. (예: `my_shop_alert_bot`)
5. BotFather가 `123456789:AAH...` 처럼 생긴 **토큰**을 보내줘요. 복사해 두세요.
   **토큰은 비밀번호와 같아서 다른 사람에게 보여주면 안 돼요.**
6. BotFather 메시지에 있는 봇 링크(`t.me/...`)를 눌러서 내 봇과의 대화를 열고 **시작(Start)** 을 눌러요.

### 2. GitHub 저장소 만들기

1. [github.com](https://github.com)에 가입하거나 로그인해요.
2. 오른쪽 위 **+** → **New repository**를 눌러요.
3. Repository name에 `shop-alert` 같은 이름을 적어요.
4. **Public**을 선택해요. (Public이어야 무료로 10분마다 돌릴 수 있어요.)
5. **Create repository**를 눌러요.

### 3. 파일 올리기

1. 새 저장소 화면에서 **uploading an existing file** 링크를 눌러요.
2. 이 폴더 **안에 있는 것 전부**(`watcher.py`, `watchlist.toml`, `README.md`, `.github` 폴더)를 끌어다 놓아요.
3. 아래쪽 **Commit changes**를 눌러요.
4. 저장소에 `.github` 폴더가 보이는지 확인해요.
   보이지 않으면 **Add file** → **Create new file**을 누르고, 파일 이름 칸에
   `.github/workflows/watch.yml`을 그대로 입력한 다음, `watch.yml` 내용을 붙여 넣고 **Commit changes**를 눌러요.

### 4. 봇 토큰 등록하기

1. 저장소의 **Settings** → 왼쪽 **Secrets and variables** → **Actions**로 가요.
2. **New repository secret**을 눌러요.
3. Name에 `TELEGRAM_BOT_TOKEN`, Secret에 1번에서 받은 토큰을 넣고 **Add secret**을 눌러요.

### 5. 내 chat id 받기

1. 텔레그램에서 내 봇에게 아무 말이나 보내요. (예: `안녕`)
2. GitHub 저장소의 **Actions** 탭 → 왼쪽 **새 상품 알림** → 오른쪽 **Run workflow** → 초록색 **Run workflow**를 눌러요.
3. 1분쯤 지나면 봇이 `이 대화의 chat id 는 123456789 이에요` 라고 답장해요.
4. 4번과 같은 방법으로 Name `TELEGRAM_CHAT_ID`, Secret에 그 숫자를 등록해요.

### 6. 시작

**Actions** → **Run workflow**를 한 번 더 눌러요. 봇이 `👀 감시 시작` 메시지를 보내면 끝이에요.
이제부터는 10분마다 저절로 확인해요.

## 텔레그램 명령어

봇과의 대화창에서 `/`를 누르면 목록이 떠요. 명령어는 다음 확인 때(최대 10분 뒤) 처리돼요.

| 명령어 | 하는 일 |
|---|---|
| `/list` | 감시 중인 페이지와 번호 보기 |
| `/add 주소` | 페이지 추가 (어떤 사이트인지 자동으로 알아내요) |
| `/add 주소 나이키 아식스` | 제목에 `나이키`나 `아식스`가 있을 때만 알리도록 추가 |
| `/remove 번호` | 감시 그만하기 |
| `/name 번호 새이름` | 알림에 보일 이름 바꾸기 |
| `/kw 번호 키워드…` | 키워드 바꾸기 (`/kw 번호`만 쓰면 키워드 없이 전부 알림) |
| 주소만 보내기 | `/add 주소`와 같아요 |

새로 추가한 페이지는 지금 올라와 있는 상품·글은 건너뛰고, **그다음부터 올라오는 것만** 알려줘요.

## 어미새 게시판 주소

| 게시판 | 추가 명령 | 참고 |
|---|---|---|
| 인기정보 | `/add https://eomisae.co.kr/fs` | 처음부터 들어 있어요. 하루 20개 정도 |
| 패션정보 | `/add https://eomisae.co.kr/os` | 한 시간에 8개 정도로 많아서 키워드를 같이 쓰는 걸 추천해요 |
| 기타정보 | `/add https://eomisae.co.kr/rt` | |
| 래플:드로우 | `/add https://eomisae.co.kr/dr` | |
| 이벤트:쿠폰 | `/add https://eomisae.co.kr/ec` | |
| 공동구매 | `/add https://eomisae.co.kr/jp` | |

**패션정보 참고:** 어미새는 로그인하지 않은 사람에게 일부 새 글을 약 1시간 뒤에 공개해요.
봇도 로그인하지 않고 보기 때문에, 그런 글은 공개된 뒤에 알림이 와요.

## 쇼핑몰 추가하기

Cafe24로 만든 쇼핑몰(국내 편집숍 상당수)은 상품 목록 페이지 주소를 `/add` 하면 돼요.
자동으로 **신상품순**으로 바꿔서 확인해요.

그 밖의 사이트도 `/add`로 먼저 시도해 보세요. "자동으로 확인할 수 없었어요"라는 답이 오면
그 사이트는 따로 맞춰 줘야 해요.

## 목록을 직접 고치기

GitHub에서 `watchlist.toml`을 열고 연필(✏️) 아이콘을 누르면 직접 고칠 수 있어요. 휴대폰 브라우저에서도 돼요.
`[[watch]]` 하나가 페이지 하나예요. `type`은 비워 두면 다음 실행 때 자동으로 채워져요.

```toml
[[watch]]
name = "어미새 패션정보"
url = "https://eomisae.co.kr/os"
keywords = ["나이키", "아크테릭스"]
```

## 문제가 생기면

- **알림이 안 와요:** 저장소 **Actions** 탭에서 최근 실행 기록을 보세요. 빨간 ✕ 표시를 누르면 이유가 나와요.
- **"N번 연속으로 확인하지 못했어요" 메시지가 와요:** 사이트 구조가 바뀌었거나 사이트가 GitHub 서버의 접속을 막은 경우예요. 다시 정상이 되면 "다시 정상적으로 확인하고 있어요" 메시지가 와요.
- **알림이 10분보다 늦게 와요:** GitHub가 붐비는 시간에는 실행이 몇 분 늦어질 수 있어요.
- **한동안 알림이 아예 없어요:** 공개 저장소에 60일 동안 변화가 없으면 GitHub가 예약 실행을 멈춰요. 이 봇은 새 글이 올라올 때마다 기록을 저장하기 때문에 보통은 멈추지 않지만, 멈췄다면 **Actions** 탭에서 **Enable workflow**를 누르세요.
- **커밋이 계속 쌓여요:** `seen.json`을 저장하느라 생기는 거라 정상이에요.

저장소가 공개라서 감시 목록은 다른 사람도 볼 수 있어요. 봇 토큰과 chat id는 Secrets에 들어 있어서 보이지 않아요.
